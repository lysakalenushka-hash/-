# Презентации по первой помощи (Тема 2)

Стиль — «Организационно-правовые аспекты оказания первой помощи»
(серые панели RGB 221, CAPS-заголовки, номер слева, cream-выноски).

Пять презентаций **без дублирования** — разные углы:

1. `Кровотечение_Обзорный_осмотр_пострадавшего.pptx` — **процесс**: зачем и как искать кровотечение.
2. `Признаки_наружного_кровотечения_и_кровопотери.pptx` — **распознавание**: признаки, виды, интенсивность.
3. `Способы_временной_остановки_кровотечения.pptx` — **техники**: давление, повязка, жгут.
4. `Последовательность_остановки_кровотечения.pptx` — **алгоритм решений**: порядок и ветвления.
5. `Остановка_кровотечения_области_тела.pptx` — **по зонам**: голова, шея, грудь, живот, конечности, смежные зоны.

```bash
python3 presentations/build_bleeding_overview.py
python3 presentations/build_signs_bleeding.py
python3 presentations/build_stop_bleeding.py
python3 presentations/build_sequence_stop.py
python3 presentations/build_body_regions.py
```
