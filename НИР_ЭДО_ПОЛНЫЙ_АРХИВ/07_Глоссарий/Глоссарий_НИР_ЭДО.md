# Глоссарий НИР: ЭДО и ЭДО в охране труда

Краткие соответствия: **ПЭП ≈ SES**, **УНЭП ≈ AES**, **УКЭП ≈ QES**. ЭЦП Беларуси и Казахстана ближе к УКЭП. Скан картинки подписи — не электронная подпись.

- **ДТС** — доверенная третья сторона ЕАЭС ([Решение ЕЭК № 120](https://docs.eaeunion.org/documents/414/7596/)).
- **Zugang** — немецкое правило доставки QES так, чтобы адресат мог проверить подпись.
- **Form 6** — сербский бумажный учёт обученных при электронных остальных формах ОТ.
- **106B** — кенийский сертификат допустимости электронной записи.
- Журнал инструктажа в РФ исключён из КЭДО ([ст. 22.1 ч. 3 ТК](https://www.consultant.ru/document/cons_doc_LAW_34683/)); протокол проверки знания по [ПП 2464 п. 91–93](https://www.consultant.ru/document/cons_doc_LAW_405146/) может быть электронным.
