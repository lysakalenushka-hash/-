# Анализ законодательства иностранных государств в части ЭДО в охране труда

**Предмет.** Электронный документооборот в OT/OSH: инструктажи и обучение, оценка рисков, учёт травматизма, ознакомление с ЛНА, взаимодействие с регулятором.

**Комплект Word:** папка `edo_ot_by_country/`, архив `ЭДО_в_ОТ_по_странам_Word.zip`.

## Ключевой вывод по РФ

Ч. 3 ст. 22.1 ТК РФ исключает из КЭДО документы о прохождении инструктажей по ОТ и акты НС. За рубежом электронные записи обучения/инструктажа обычно допустимы при идентификации и целостности; **Казахстан прямо разрешает электронный журнал инструктажей с ЭЦП**.

## Сводка по юрисдикциям

| Юрисдикция | ЭДО в ОТ — суть | Что взять РФ |
| --- | --- | --- |
| ЕС | Формат документов гибкий; сила ЭП — eIDAS; цифровые РА/обучение | Легализовать e‑журналы; шаблоны ОПР |
| UK | Goal‑setting; электронные РА и permit‑to‑work | E‑наряды‑допуски; критерии sufficient record |
| США | Electronic training records OK; ITA по травмам | Certification record + audit trail; e‑отчётность травм |
| Сингапур | Госреестр TRS для проверки WSH‑обучения | Сервис проверки обучения до допуска |
| Китай | ЭП по общему закону применяется к safety docs | Единая логика ЭП и для инструктажей |
| Казахстан | Прямо: электронный журнал инструктажа + ЭЦП | Самый близкий образец для правки ТК/2464 |
