## Логика глав НИР

1. **Глава 1** — общетеоретический раздел о регулировании ЭДО за рубежом (модели, не страны подряд).
2. **Глава 2** — зарубежный опыт ЭДО в ОТ (по процессам: инструктаж, обучение, ОПР, наряд, НС).
3. **Глава 3** — сравнение с РФ (63‑ФЗ, ст. 22.1 ТК РФ, ПП № 2464) и предложения.
