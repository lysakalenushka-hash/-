### Листы Excel

1. **Сводка изменений** — ключевые выводы и легенда
2. **Структура тем** — соответствие тем 1–4 между редакциями
3. **Пофразовый анализ** — детальное сравнение формулировок
4. **Добавлено и исключено** — списки новых и удалённых позиций
5. **Полные тексты рядом** — блоки целиком для сверки
