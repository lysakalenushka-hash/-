# Анализ законодательства иностранных государств по ЭДО (в целом)

Актуализация: август 2026.

| Файл | Описание |
| --- | --- |
| `Анализ_законодательства_иностранных_государств_ЭДО.md` | Текстовый обзор |
| `Анализ_законодательства_иностранных_государств_ЭДО.xlsx` | Сводка, сравнительная таблица, рекомендации, источники |
| `edo_by_country/` + `ЭДО_по_странам_Word.zip` | Word по странам + сводные рекомендации |

В каждом страновом Word: обзор ЭДО, сравнительная таблица с РФ, что добавить / не переносить, ссылки на источники.

Юрисдикции: ЕС (eIDAS 2.0), Великобритания, США, Сингапур, Китай, Казахстан/ЕАЭС.
