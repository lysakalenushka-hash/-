# Тема 2. Наружные кровотечения

Стиль исходных слайдов сохранён: заголовок, линия, подзаголовок.

- Слайд **не** является изображением.
- Весь текст — **редактируемые** текстовые блоки.
- Иллюстрации из исходника — **отдельные объекты Picture** (текст с картинок снят и вынесен в текст).
- Новые слайды (пробелы по приказу № 220н) — Open Sans 46/26/32.
